## Anything weird

- Zero examples dropped — every pair tokenized within budget.
- **Deviated from spec algorithm.** The spec described a pair-level shuffle followed by post-hoc "move leaked chunk to majority split". Empirically that gutted val/test (~30/150 pairs vs target ~935/1,873) because each chunk has ~5 pairs and the 5% val ratio rarely makes val the majority for any chunk. We instead shuffle and partition at the **chunk_id** level, which leaves leakage impossible by construction and hits the requested fractions cleanly.
- CRS held-out folder is `crs_2026_law_enforcement_cuas_IN12661` in the corpus (the doc-ID suffix `_IN12661` is appended). Matched via prefix rule `folder == prefix OR folder.startswith(prefix + '_')`.
